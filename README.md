# Bunju Foundation

Build the foundation of a web app called Bunju — a global platform connecting

verified talent, freelancers, founders, startups, teams, and investors around proof of

work rather than credentials or connections.

Set up:

- A design system: clean, modern, high-trust fintech/professional-network aesthetic

  (think the trustworthiness of a banking app combined with the energy of a talent

  marketplace). Use a confident primary color, a neutral dark-mode-first palette,

  generous whitespace, and clear typographic hierarchy. Avoid generic SaaS-template

  look — this should feel premium and intentional.

- A component library: cards, badges (especially "verified" badges), progress rings,

  data tables, modals, toasts, empty states, skeleton loaders.

- Global navigation shell with: sidebar (Dashboard, Discover, Profile, Workspaces,

  Wallet, Messages, Settings) and a top bar with notifications, search, and account menu.

- A public marketing landing page explaining the platform's core philosophy: "Proof of

  ability matters more than claims, connections, or location." Include sections for

  Talent, Founders, Companies, and Investors, and a clear CTA to sign up.

- Responsive layout that works on mobile and desktop.

Do not build authentication, database logic, or real functionality yet — this phase is

purely the visual shell, routing, and component system.
